# Incident INC-2041, 2041-03-04

## Timeline

* 02:12:02 UTC: payments-api v412 deployed; max_pool_size changed from 200 to 20.
* 02:17:09 UTC: first payments-db connection pool exhausted error.
* 02:31:05 UTC: on-call acknowledged the page.
* 02:38:20 UTC: rollback to v411 started; max_pool_size restored to 200.
* 02:41:33 UTC: error rate back to baseline.

## Root cause

Deploying payments-api v412 reduced max_pool_size from 200 to 20, which exhausted the
payments-db connection pool.

## Customer impact

Charges returned 503 for acme-retail, northwind and globex.
